## Deskripsi Program

### Soal 1 - `tugas1_bmi.py`
Meminta input berat (kg) dan tinggi (m), menghitung BMI dengan fungsi `hitung_bmi()`
(`berat / (tinggi * tinggi)`), lalu `tentukan_kategori()` memakai if-elif-else:
kurang (<18.5), normal (18.5-24.99), berlebih (25-29.99), obesitas (>=30).

### Soal 2 - `tugas2_nilai_mahasiswa.py`
Menyimpan 6 mahasiswa dalam list of dictionary. Nilai akhir = 30% UTS + 40% UAS + 30% Tugas.
Grade ditentukan A (>=80), B (70-79), C (60-69), D (50-59), E (<50). Hasil ditampilkan
dalam tabel rapi, lalu dicari mahasiswa dengan nilai akhir tertinggi dan terendah.

### Soal 3 - `math_operations.py` & `main.py`
Modul berisi konstanta `PI`, fungsi luas/keliling (persegi, persegi panjang, lingkaran),
dan konversi suhu (Celsius ke Fahrenheit & Kelvin). `main.py` mengimpor modul dengan dua cara
(`import math_operations as mo` dan `from math_operations import ...`) dan menguji semua fungsi.

## Cara Menjalankan
```bash
python tugas1_bmi.py
python tugas2_nilai_mahasiswa.py
python main.py
```
